# Library System

## Project Description
This is a Library Management System for tracking books, members, borrowings, and librarians. 

## Tables
- Books: Stores book details
- Members: Stores library member details
- Borrowings: Tracks which member borrowed which book
- Librarians: Stores librarian details

## Features Implemented
- Database schema with 4 tables
- Sample data insertion (10+ records per table)
- SQL operations: SELECT, INSERT, UPDATE, DELETE, JOIN, SUBQUERY
- Normalization (UNF → 3NF)
- Indexing demonstration

## Reflection
I learned database normalization, SQL operations, and indexing benefits. Using GitHub for version control helped track progress efficiently.
